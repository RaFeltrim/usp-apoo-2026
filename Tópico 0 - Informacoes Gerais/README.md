## 📊 Critérios de Avaliação Oficial

- **Exercícios (`MExercícios` — Peso 25%):** Excelente (10,0) · Muito Bom (8,5) · Bom (7,0) · Regular (5,5) · Ruim (4,0) · Não entregou (0,0)
- **Projeto (`MProjeto` — Peso 35%):** Desafio de desenvolvimento aplicando as teorias de APOO
- **Prova (`MProva` — Peso 40%):** Avaliação final teórica/prática
- **Cálculo da Média Final (`MF`):**
  - Se `MProva >= 5` **E** `MExercícios >= 5` **E** `MProjeto >= 5`:
    `MF = (MProva * 0.40) + (MExercícios * 0.25) + (MProjeto * 0.35)`
  - Caso contrário:
    `MF = min(MProva, MExercícios, MProjeto)`
- **Aprovação:** `MF >= 5,0` **E** Frequência mínima de `70%` *(Recuperação para `3,0 <= MF < 5,0` com frequência >= 70%)*.
